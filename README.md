
# Biblioteca Digital UniFECAF

Projeto acadêmico desenvolvido para a disciplina **Design Web**, do curso de Análise e Desenvolvimento de Sistemas (ADS) da UniFECAF.

## Sobre o projeto

A Biblioteca Digital UniFECAF é uma interface web criada para apresentar livros, unidades e informações de contato da biblioteca, facilitando o acesso dos estudantes aos conteúdos acadêmicos.

O projeto foi baseado no protótipo disponibilizado na atividade da disciplina, mantendo suas principais seções e utilizando uma identidade visual com as cores azul, branco e verde.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Características da interface

- Menu de navegação entre as seções.
- Banner principal.
- Apresentação da biblioteca.
- Área de livros com imagens e descrições.
- Seção de unidades.
- Informações de contato.
- Layout responsivo para computadores e smartphones.
- Aplicação de princípios básicos de acessibilidade.

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Opcionalmente, utilize a extensão Live Server para visualizar as alterações durante o desenvolvimento.
